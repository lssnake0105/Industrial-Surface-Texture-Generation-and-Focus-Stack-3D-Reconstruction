# Data Notes

This project used data that is not fully uploaded to GitHub.

## Data Source

- Real focus-stack images collected from local surface samples during the SRTP project.
- Simulated focus stacks generated by project scripts from synthetic height maps, surface texture parameters, and glare-risk settings.
- Intermediate arrays and metrics generated during algorithm comparison and model-training experiments.

## Data Format

- Real samples: image sequences such as `.jpg`, `.png`, `.bmp`, `.tif`, or similar focus-stack frames.
- Simulated samples: image frames, `.npy` depth maps, CSV metrics, JSON manifests, and rendered result panels.
- Training and evaluation outputs: CSV logs, model predictions, confidence maps, and comparison figures.

## Access

The full raw datasets are kept locally because they may contain large files, unfinished experiment material, and project-specific sample images. They should be reviewed manually before any public release.

## Reproduction

Without the raw focus-stack data, readers can still inspect the public result figures and run the synthetic sample generation scripts in `src/`. Real-sample evaluation scripts require the local focus-stack folder structure described in the project notes.
