# 后续算法探索方向：从通用滤波转向样品特异与成像机理约束

## 1. 当前判断

中期之后引入 Savitzky-Golay（SG）滤波思想进行**二维空间滤波**后，结果略有改善但有限，这个现象是合理的。这里的 SG 不是沿 Z 轴焦点曲线做“光谱式平滑”，而是把 SG 的局部多项式拟合思想用于高度图或二维重建结果的空间平滑：在局部窗口内用低阶多项式近似表面形貌，从而降低随机噪声，同时尽量保留局部曲面趋势。

它比普通高斯滤波更“保形”，因为高斯滤波只做加权平均，而 SG 空间滤波会尝试保留局部斜率、曲率等多项式结构。但它本质上仍是**空间后处理**，不能判断一个高度点到底来自真实表面、反光伪峰、低纹理噪声峰，还是由镜头像差/场曲引起的系统性偏移。

因此后续最有价值的方向不是继续换滤波器，而是把算法层级前移：从“高度图后处理”转向“焦距堆栈成像校正 + 聚焦曲线置信度 + 样品特征先验 + 光学噪声/像差模型”。一句话说，后续应做 **特异算法**，而不是继续堆通用滤波。

## 2. 为什么 SG 改善有限

### 2.1 DFF 误差不是单纯的高频噪声

当前算法是先对每一层图像计算 Laplacian/LoG 聚焦响应，然后对每个像素取最大响应层作为高度。如果某个像素因为反光、暗噪声、低纹理或局部饱和选错了焦点层，那么后续再对高度图做 SG、Gaussian、Median 或开运算，只能把错误高度“平滑得更连续”，不能恢复正确焦点。

### 2.2 二维空间 SG 适合保形平滑，不适合独立解决缺陷识别

二维空间 SG 的假设是局部邻域内的高度面可以用低阶多项式逼近。这对缓慢变化的表面区域是合理的，因此它能改善高度图连续性；但表面缺陷常常表现为突变、尖峰、深谷、边界和方向性纹理，未必满足局部多项式平滑假设。过强 SG 会把真实沟槽、孔边缘、层纹峰谷当作噪声抹平；过弱 SG 又无法压制工业相机噪声、固定模式噪声和错误焦点层带来的散点。

所以，你已经做的 SG 空间滤波更适合被表述为：**一种保形后处理尝试，能轻微改善视觉连续性，但无法从根本上提升焦点层判定正确率。**

### 2.3 真正瓶颈在“峰值可信度”

DFF 的核心问题不是有没有峰，而是“这个峰是否可信”。在金属反光、3D 打印纹理、钥匙沟槽等不同样品中，聚焦曲线可能出现多峰、宽峰、弱峰、饱和伪峰和边缘响应伪峰。后续应为每个像素或超像素输出一个深度值和一个置信度，而不是简单输出 argmax 层号。

## 3. 主路线：眩光感知-置信度引导 DFF

建议把后续主线命名为：

**GA-CG-DFF：Glare-Aware and Confidence-Guided Depth from Focus**  
中文可写作：**眩光感知与置信度引导的变焦显微三维重建算法**。

这条路线最适合放进结题展望或后续课题，因为它既延续了你已经做过的 SG/滤波探索，又能自然升级到样品特异算法。

目前应把“眩光/强反射”作为光学噪声与像差机理中的第一优先级。它不只表现为像素 255 饱和，更常见的是局部高亮、反射梯度、跨层亮度漂移和高光边缘伪纹理。这些因素会使 Laplacian/LoG 聚焦评价在错误焦平面产生高响应，进而造成焦点层误选。对应的详细路线和现有数据诊断已整理在 `眩光感知DFF后续路线.md` 和 `结题交付包/05_图表与结果/眩光主线分析/`。

### 3.1 眩光与成像校正层

目标：先识别强反射、高亮和照明不均带来的不可靠区域，再做聚焦评价。

建议模型：

```text
I_k'(x,y) = [I_k(x,y) - D(x,y)] / [F(x,y) - D(x,y) + eps]
```

其中：

- `I_k(x,y)` 是第 k 层原图。
- `D(x,y)` 是暗场/偏置项，对应暗电流、读出噪声、DSNU 等。
- `F(x,y)` 是平场响应，对应照明不均、镜头渐晕、PRNU、像素响应不均。
- 如果没有真实暗场和平场，可先用焦距堆栈的低分位图、均值图、大尺度模糊图做近似估计。

同时生成眩光/无效像素掩膜：

- 硬饱和像素：像素接近 245-255，纹理信息被截断。
- 软眩光像素：未完全饱和，但亮度显著高于局部背景。
- 高光边缘像素：亮度梯度很强，容易产生 Laplacian 伪响应。
- 低信号/低纹理像素：信噪比低或局部方差太小，聚焦曲线没有明确峰值。
- 跨层漂移像素：高亮位置或强度随 Z 层明显变化，容易产生多峰。

### 3.2 聚焦曲线层：把 SG 从二维空间后处理前移到 Z 向峰值建模

你已经做过的是二维空间 SG，即对重建后的高度图或结果图做局部曲面平滑。后续更有研究价值的升级，是把 SG 的局部多项式拟合思想前移到 DFF 的核心环节：对每个像素或超像素沿 Z 轴的聚焦响应曲线做处理。

也就是说，不是只平滑最终高度图，而是在选取最大聚焦层之前处理焦点曲线：

```text
原始焦点曲线 F(z)
-> 基线校正
-> SG 平滑
-> 峰值拟合
-> 输出 z_peak 和 confidence
```

推荐置信度指标：

- 峰值锐度：峰附近二阶曲率越大，焦点越明确。
- 主峰/次峰比：次峰接近主峰时说明深度不可靠。
- 峰宽 FWHM：峰太宽说明景深或纹理导致定位不准。
- 曲线信噪比：峰值相对基线波动是否足够高。
- 饱和惩罚：该像素若在若干层饱和，降低置信度。
- 纹理惩罚：局部方差过低则降低置信度。

一个可实现的置信度形式：

```text
C = peak_sharpness * peak_ratio * texture_score * (1 - saturation_ratio)
```

最终输出不只是高度 `z(x,y)`，还包括置信度 `C(x,y)`。这会让结果从“硬选层”变成“带可信度的重建”。

### 3.3 置信度引导的深度融合

对高置信度区域直接采用峰值拟合深度；对低置信度区域，不再相信 argmax，而是用周围可靠区域和图像边缘约束补全。

可写为优化问题：

```text
min_z  Σ_i C_i (z_i - z_i^0)^2 + λ Σ_(i,j) w_ij (z_i - z_j)^2
```

解释：

- 第一项：置信度高的点尽量保留原始 DFF 深度。
- 第二项：相邻点保持合理连续。
- `w_ij` 由全聚焦图边缘、纹理方向或样品先验决定。
- 缺陷边界处降低平滑权重，避免把孔洞、沟槽、层纹抹平。

这一步比单纯高斯滤波更强，因为它知道哪里可信、哪里不可信，也知道哪里应该平滑、哪里应该保边。

## 4. 样品特异算法方向

### 4.1 3D 打印层纹：方向结构张量 + 周期纹理约束

3D 打印层纹不是随机缺陷，而是具有方向性和周期性的表面结构。适合做特异算法。

推荐路线：

1. 由全聚焦图或伪彩色高度图计算结构张量，得到主纹理方向。
2. 沿层纹方向做强平滑，垂直层纹方向保留周期起伏。
3. 用 Gabor / Log-Gabor / FFT 估计层纹周期、幅值和方向一致性。
4. 输出层纹评价指标：层距、层纹幅值、局部错层位置、周期稳定性。

这比“把所有样品都高斯滤波”更专业，因为它利用了 FDM 层纹的物理生成特征。

### 4.2 金属磕碰孔：反光掩膜 + 凹坑拓扑先验

金属表面主要问题是镜面反射、局部饱和和边界伪高频。磕碰孔的形态则通常是局部盆地状凹陷。

推荐路线：

1. 先检测饱和/高亮区域，生成反光不可靠掩膜。
2. 在高度图上做 robust plane removal，去除整体倾斜。
3. 用 black top-hat、LoG blob 或 watershed 找局部凹陷盆地。
4. 对每个候选凹坑计算面积、等效直径、最大相对深度、边界陡峭度。
5. 对反光掩膜内区域不直接判定深度，而是从周围可信边界插值。

这样算法会更像“磕碰孔检测算法”，而不是泛泛的三维重建可视化。

### 4.3 钥匙沟槽/刻痕：Hessian 线结构 + 横截面轮廓

钥匙纹路和沟槽具有明显线状结构。适合用线结构增强，而不是只用局部 Laplacian。

推荐路线：

1. 用 Hessian/Frangi/Steger 类线结构检测器增强沟槽中心线。
2. 沿沟槽方向追踪中心线，垂直方向提取横截面高度剖面。
3. 输出沟槽宽度、相对深度、边缘锐度和方向一致性。
4. 对沟槽区域采用各向异性滤波：沿沟槽方向平滑，垂直沟槽方向保边。

这个方向可以把“能看到钥匙纹路”升级为“能定量描述沟槽轮廓”。

## 5. 光学噪声/像差机理方向

### 5.1 相机噪声建模

工业相机主要噪声可以分为：

- Photon shot noise：光子到达的随机性，信号越弱相对噪声越强。
- Read noise：读出电路噪声，在低照度下尤其明显。
- Fixed pattern noise：固定模式噪声，包括 DSNU 和 PRNU。
- Demosaicing/color noise：彩色相机插值带来的颜色噪声；若使用灰度工业相机，这部分较弱。

后续算法可以把噪声方差写成：

```text
σ²(I) = aI + σ_read² + σ_FPN²
```

然后在聚焦评价中降低低信噪比像素的权重。这样比盲目滤波更接近工业相机成像机理。

### 5.2 场曲与像差补偿

显微系统的最佳焦面可能不是理想平面，视场边缘也可能因场曲、球差、像散或照明不均导致聚焦曲线形状变化。如果不补偿这些因素，算法会把光学系统误差误认为样品高度。

可行方案：

1. 对近似平坦样品或低频背景区域估计系统焦面 `z0(x,y)`。
2. 将重建高度改为相对系统焦面：

```text
z_corrected(x,y) = z_raw(x,y) - z0(x,y)
```

3. 对视场不同区域使用不同的聚焦评价参数，例如中心区、边缘区分别设置窗口大小和置信度阈值。
4. 如果后续做深度学习，应考虑“像差感知训练”，即让模型见过视场不同位置的 PSF/模糊变化。

## 6. 推荐优先级

### 优先级 A：最值得马上做

**从二维空间 SG 升级为 Z 向焦点曲线 SG + 置信度图 + 低置信度区域保边补全。**

原因：不需要新硬件，不需要大量数据，且能直接解释为什么之前的二维空间 SG 改善有限：它只在高度图生成之后修补结果，而新的方法在高度图生成之前判断“哪个焦点峰可信”。

最小可实现版本：

1. 对现有焦距堆栈计算 focus volume。
2. 对每个像素或 5×5 超像素的 Z 向聚焦响应曲线做 SG 平滑。
3. 计算主峰/次峰比、峰宽、峰曲率、饱和率。
4. 输出高度图和置信度图。
5. 只在低置信度区域做边缘引导补全。

### 优先级 B：最适合写成特色

**样品特异算法：3D 打印层纹方向约束、金属凹坑拓扑约束、钥匙沟槽线结构约束。**

原因：它能把你的项目从“我试了几种滤波”提升到“针对不同材料和缺陷形态构建特异检测策略”。

### 优先级 C：更长期、更像科研

**成像机理模型：暗场/平场校正、PRNU/DSNU 估计、场曲/像差补偿、PSF/MTF 匹配聚焦评价。**

原因：这条路线更专业，但需要更多校准数据和实验设计。适合作为后续论文或继续 SRTP 的研究主线。

## 7. 可以写进结题报告的表述

中期之后，项目进一步尝试了多种后处理滤波策略，包括中值滤波、高斯滤波、形态学开运算以及引入 Savitzky-Golay 局部多项式拟合思想的二维空间滤波。实验表明，SG 空间滤波相较普通平滑方法能够更好地保留局部曲面趋势，在一定程度上改善高度图连续性并降低局部噪声，但整体提升有限。其原因在于 DFF 重建误差并非单纯来源于高度图高频噪声，而更多来自焦点峰值选取阶段的低纹理、反光饱和、工业相机噪声、照明不均和显微系统像差等因素。空间后处理滤波无法纠正已经选错的焦点层，过强平滑还可能削弱真实缺陷边界。

因此，后续研究将从通用空间滤波转向基于成像机理和样品特征的特异算法：一方面在焦距堆栈输入端引入暗场/平场校正、饱和掩膜和噪声权重；另一方面将 SG 从二维高度图后处理前移到 Z 向聚焦响应曲线层面，结合峰值拟合和置信度评价，输出带可信度的深度图；最后针对 3D 打印层纹、金属凹坑、钥匙沟槽等不同样品建立方向性、拓扑性或线结构先验，实现更稳健的三维缺陷识别。
