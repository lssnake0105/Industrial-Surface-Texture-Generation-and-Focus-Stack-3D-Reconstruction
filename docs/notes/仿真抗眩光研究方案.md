# 仿真数据驱动的抗眩光 DFF 原型研究方案

## 1. 结论先行

可以完成该方向的原型研究，但需要分清两个层级：

- **5 小时内可完成**：用 Python 近似物理仿真生成金属表面深度真值、加工纹理、镜面高光、相机噪声和焦距堆栈，训练一个轻量 CNN/UNet 做抗眩光深度恢复，并输出合成域验证指标。
- **严格物理光追版本**：需要 BlenderProc/Blender-Cycles 或 Mitsuba 3，建立相机、镜头、光源、金属 BRDF、焦距扫描和相机噪声模型。该版本更科研，但通常不适合在 5 小时内从零安装、建模、渲染、训练、验证全部完成。

因此推荐路线是：

```text
第 1 阶段：轻量近似物理仿真 + 小网络闭环验证
第 2 阶段：BlenderProc/Mitsuba 光追替换简化成像模块
第 3 阶段：真实焦距堆栈域适配 + 高置信伪标签/标准样块验证
```

本次已完成第 1 阶段的原型验证。输出位置：

`结题交付包/05_图表与结果/仿真抗眩光原型/`

核心结果：在合成验证集上，DFF 基线归一化 MAE 为 `0.1093`，轻量 TinyCNN 为 `0.0666`，合成域误差下降约 `39.1%`。该结果只能说明仿真闭环可行，不能直接声称真实工业样品泛化有效。

## 2. 与现有项目的关系

现有项目已经完成了真实焦距堆栈上的 GA-CG-DFF 启发式原型，即：

```text
真实焦距堆栈 -> 眩光风险诊断 -> 聚焦评价降权 -> 置信度图 -> 低置信补全
```

本方案进一步补上一个关键缺口：真实样品缺少标准高度真值，因此无法直接训练监督模型。仿真数据的价值在于生成可控真值：

```text
可控深度真值 -> 金属反射/眩光成像 -> 模拟焦距堆栈 -> DFF误差 -> 网络学习抗眩光恢复
```

它适合写成“后续研究路线”，不建议替代结题主成果。

## 3. 深度真值与工业加工噪声建模

### 3.1 深度真值

可以生成以下几类简单但有效的三维表面：

- 平面倾斜和低频翘曲：模拟样品安装倾角、基底不平。
- 周期性刀纹/层纹：模拟车削、铣削、3D 打印层纹或规则加工纹。
- 随机粗糙度：使用高斯随机场、分形噪声或多尺度噪声生成表面粗糙。
- 局部凹坑：用椭圆高斯凹陷模拟磕碰孔、腐蚀坑、压痕。
- 线状划痕/沟槽：用窄高斯带或曲线带模拟钥匙纹路、划伤、加工槽。

本次原型采用了以上混合模型，并将训练真值量化到 `1/64` 的归一化深度间隔。这样做的意义是避免给网络一个远高于系统真实测量能力的“过精细真值”。

### 3.2 工业加工噪声

建议把加工噪声拆成三类：

- **几何噪声**：刀纹周期、微小振纹、坑洞、划痕、边缘毛刺。
- **材料噪声**：表面粗糙度变化、氧化/镀层不均、局部反射率变化。
- **成像噪声**：shot noise、read noise、固定图案噪声、PRNU/DSNU、量化噪声。

严格相机噪声可以参考 EMVA 1288 的机器视觉相机表征框架；原型阶段可用 Poisson-Gaussian 噪声、行列偏置、像素响应不均来近似。

## 4. 金属反射与眩光机理

### 4.1 单一金属材料假设

若假设单一金属材料，推荐使用 microfacet BRDF 作为核心反射模型：

```text
I = diffuse + specular
specular = D(h, roughness) * F(v,h) * G(l,v,h) / (4(n·l)(n·v))
```

实际实现时可以先做简化：

```text
specular ≈ F0 * (n·h)^shininess * (n·l)
shininess 与 roughness 负相关
```

眩光不只来自像素饱和，还包括：

- 镜面反射高光斑。
- 高光边缘形成的强梯度伪纹理。
- 传感器饱和导致的局部信息截断。
- 光晕/bloom 造成的周边污染。
- Z 向扫描时高光强度和位置变化，导致焦点曲线多峰。

### 4.2 本次原型的眩光生成

本次 `simulate_antiglare_prototype.py` 中采用了轻量近似：

- 根据深度梯度估计表面法线。
- 给定随机方向光和观察方向。
- 用简化金属镜面项生成 specular map。
- 将高光扩散为 bloom，并随焦距层发生亮度漂移。
- 加入 Poisson-Gaussian 噪声、PRNU/DSNU 和 8-bit 量化。

它不是严格光追，但足够用于验证算法闭环。

## 5. 物理模拟与光线追踪路线

### 5.1 首选：BlenderProc + Blender Cycles

BlenderProc 适合做“数据集生产线”。官方说明显示，它基于 Blender 生成照片级合成数据，可输出 color、depth、distance、surface normals、semantic segmentation，并保存为 HDF5、BOP 或 COCO 等格式。它的优势是：

- Python API 完整，适合批量生成数据。
- 可用 Blender/Cycles 的 path tracing 机制生成较真实光照。
- 能直接输出深度、法线、分割等监督标签。
- 更容易做多样化场景和域随机化。

对本项目而言，推荐用 BlenderProc 做：

```text
金属高度网格 -> 材质/粗糙度/光源随机化 -> 多焦距相机渲染 -> RGB/Depth/Normal 输出
```

焦距堆栈可通过改变相机 focus distance 或样品 Z 位置实现。Blender 官方相机文档中，Depth of Field 可通过 focal point/focal distance 控制，Aperture/F-Stop 控制离焦模糊强度；这与 DFF 的焦距扫描机制相匹配。

### 5.2 更严谨：Mitsuba 3

Mitsuba 3 更适合科研级物理渲染，尤其是：

- 需要 spectral rendering。
- 需要 polarized rendering。
- 需要 differentiable rendering。
- 需要更精细控制 BSDF、光照、积分器和采样。

它的官方文档说明支持 CPU/GPU、多种颜色表示、谱渲染和偏振变体。若后续要研究“交叉偏振抑制金属眩光”，Mitsuba 3 比 BlenderProc 更合适。

### 5.3 不推荐一开始就做的方向

不建议一开始就追求完整 CAD/真实镜头/真实镀层参数/全波光学级模拟。原因是：

- 参数获取困难。
- 渲染耗时高。
- sim-to-real gap 仍然存在。
- 对结题或短期论文雏形帮助不如先跑通闭环。

更合理的是先做可控简化，再逐步替换模块。

## 6. 深度学习抗眩光模型设计

### 6.1 输入输出

推荐输入：

```text
X = [焦距堆栈 I_1...I_K, 眩光风险图 R, DFF基线深度 Z_dff, 焦点置信度 C]
```

推荐输出：

```text
Y = 相对深度图 Z
```

可选多任务输出：

```text
Y = [深度图 Z, 低置信区域 mask, 眩光区域 mask]
```

### 6.2 网络结构

5 小时内推荐：

- Tiny U-Net：最稳，输入多通道焦距堆栈，输出深度。
- Residual CNN：更轻量，适合直接学习 DFF error correction。
- 2.5D 网络：先对每层提特征，再沿 Z 轴做注意力/soft argmax。

不建议一开始使用大模型或复杂 Transformer，因为数据量不足，调参成本高。

### 6.3 损失函数

推荐：

```text
L = L1(Z_pred, Z_gt)
  + λ1 * gradient_loss(Z_pred, Z_gt)
  + λ2 * glare_weighted_loss
  + λ3 * smoothness_loss(masked by image edge)
```

其中 `glare_weighted_loss` 提高高眩光区域权重，但不能让网络把真实缺陷边界也抹平。

### 6.4 真实数据如何参与

真实表面数据没有精确真值时，不建议直接监督训练。推荐三种方式：

- **高置信伪标签**：只用 GA-CG-DFF 中高置信区域作为伪真值，低置信/眩光区域不参与监督或只参与一致性约束。
- **域适配**：让合成图像的亮度分布、噪声、饱和比例、纹理频谱接近真实焦距堆栈。
- **自监督一致性**：预测深度重新解释焦距响应峰值，要求预测结果与焦点曲线、边缘结构一致。

如果后续有标准台阶、标准粗糙度样块或白光干涉/共焦结果，才适合做真实监督验证。

## 7. 本次轻量原型执行结果

脚本：

`simulate_antiglare_prototype.py`

输出：

`结题交付包/05_图表与结果/仿真抗眩光原型/`

本机环境：

- Python 3.12.7
- PyTorch 2.7.1 + CUDA 11.8
- CUDA 可用
- 当前未检测到可直接调用的 `blender`
- Torch 运行时需要设置 `KMP_DUPLICATE_LIB_OK=TRUE` 避免 OpenMP 重复初始化报错，该做法适合临时原型，不建议作为长期工程环境方案

训练设置：

- 合成训练样本：192
- 合成验证样本：48
- 图像尺寸：64 × 64
- 焦距堆栈层数：9
- 网络：Tiny U-Net 风格 CNN
- 训练轮数：10
- 总运行时间：约 30.5 秒

指标：

| 方法 | MAE | RMSE | P90误差 | 高眩光区MAE |
|---|---:|---:|---:|---:|
| DFF 基线 | 0.1093 | 0.1450 | 0.2344 | 0.1492 |
| 眩光降权 DFF | 0.1095 | 0.1450 | 0.2344 | 0.1472 |
| TinyCNN 合成训练 | 0.0666 | 0.0834 | 0.1327 | 0.0757 |

判断：

- CNN 在合成验证集上确实学到了比传统 DFF 更平滑、更接近真值的深度恢复。
- 启发式眩光降权单独使用对整体 MAE 改善很有限，但在高眩光区 MAE 略有改善，说明它更适合作为网络输入先验和置信度机制。
- 该结果证明“仿真监督 + 抗眩光深度恢复”方向可行，但不证明真实工业泛化已经完成。

## 8. 高分辨率样本扩展验证

根据进一步要求，已新增 `simulate_antiglare_highres_samples.py`，在 360p 与 540p 分辨率下生成更复杂的仿真样本。输出位置：

`结题交付包/05_图表与结果/仿真抗眩光高分辨率样本/`

新增内容包括：

- 分辨率从原 `64×64` 扩展到 `640×360` 和 `960×540`。
- 深度范围增大到约 `760-1450 um`。
- 几何结构加入倾斜平面、细微刀纹、多尺度腐蚀坑、深凹坑、抬边 crater、细槽和混合划痕。
- 光照从斜入射近似改为同轴光照假设，观察方向与主光照方向近似一致。
- 引入杂散光：veiling glare、低频照明漂移、高光 bloom、椭圆 ghost flare。
- 加入简化相机设置：工作距离 `25 mm`，水平视场角 `8°`，传感器宽度 `6.4 mm`，F 数 `5.6`。
- 由相机假设推算：物方视场宽约 `3.50 mm`；360p 物方像素约 `5.46 um/px`，540p 物方像素约 `3.64 um/px`；等效焦距约 `45.7 mm`。

关键验证结果：

| 阶段 | 结论 |
|---|---|
| 低分辨率 CNN 直接迁移 | 不稳定，平均误差明显高于 DFF，说明 64×64 小模型不能直接放大到 360p/540p |
| 128×128 高分辨率 patch 微调 | 平均 MAE 从 DFF 的约 `80.60 um` 降到 `54.58 um`，相对改善约 `13.7%` |
| 细微刀纹/细槽场景 | patch 微调仍可能比 DFF 差，说明网络容易平滑细节，需要多尺度或边缘保持损失 |
| 深凹坑/大深度范围场景 | patch 微调改善明显，说明深度学习更适合修正大范围眩光和焦点误选 |

这次扩展给出的更稳妥结论是：高分辨率仿真抗眩光方向可行，但不能只靠低分辨率原型外推；必须进行高分辨率 patch 训练、多尺度结构设计，且需要加入细节保持约束。

最新版本已将高分辨率主流程统一改为 `17` 层焦距堆栈，并新增 `540p_A型突起刃脊_柏林噪声` 样品。该样品由 `surface_sample_generator.py` 生成，表面为突起 A 型刃脊，叠加柏林噪声，用于模拟尖锐刃口/脊线结构在同轴光照和杂散光下的重建难点。17 层 patch 模型重新训练后，七组高分辨率样本平均 DFF MAE 约 `69.69 um`，17 层 patch 模型平均 MAE 约 `30.51 um`，相对 DFF 平均改善约 `32.0%`；A 型刃脊样品中 DFF MAE 为 `124.58 um`，patch 模型 MAE 为 `48.01 um`，改善约 `61.5%`。

同时新增三维样品生成器，可通过命令行选择基线类型和噪声类型：

```text
python surface_sample_generator.py --baseline a_ridge --noise perlin
```

支持的基线类型包括：山峰、山脊、A 型刃脊、阶跃、周期；支持的噪声类型包括：无、平滑高斯、分形、柏林、条纹。输出包括深度 `.npy`、二维伪彩色深度图和三维预览图，可作为后续仿真数据扩增入口。

运行环境注意：`surface_sample_generator.py` 已去除 OpenCV 依赖，最小依赖为 `numpy` 和 `matplotlib`；完整高分辨率抗眩光仿真仍需要 `opencv-python` 和 `torch`。若使用项目 `.venv`，可执行：

```text
".venv\Scripts\python.exe" -m pip install -r requirements-simulation.txt
```

此外，传统 DFF 基线的 Z 向采样步长确实偏粗。以 540p 大深度复合凹坑为例，深度范围约 `1450 um`，9 层焦距堆栈对应约 `181.25 um/层`，DFF MAE 为 `149.42 um`；增加到 17 层后步长约 `90.62 um/层`，MAE 降至 `96.63 um`；增加到 25 层后步长约 `60.42 um/层`，MAE 进一步降至 `74.86 um`。这说明此前 9 层 DFF 基线对大深度样本并不够公平。

但层数增加并不保证所有样本单调变好：在 360p 深凹坑样本中，17 层从 `196.22 um` 改善到 `187.02 um`，25 层反而回升到 `200.30 um`。原因可能是更密采样也会提供更多眩光伪峰候选，若聚焦评价函数缺少置信度判别和亚层峰值拟合，argmax 仍可能被强反射误导。因此后续推荐把 DFF 基线改为：

```text
更密 Z 采样 + 峰值置信度/主次峰比 + 二次或高斯亚层峰值拟合 + 眩光风险降权
```

## 9. 5 小时内的可执行排程

如果目标是 5 小时内得到可展示结果，推荐如下：

| 时间 | 工作 | 产出 |
|---:|---|---|
| 0-0.5 h | 固定简化物理模型和网络输入输出 | 方案参数表 |
| 0.5-1.5 h | 生成合成深度真值、金属高光、焦距堆栈 | 合成数据集与样例图 |
| 1.5-2.5 h | 实现 DFF 基线、眩光风险图和置信度图 | 基线误差表 |
| 2.5-3.5 h | 训练 Tiny U-Net/Residual CNN | 训练曲线和模型 |
| 3.5-4.3 h | 合成验证集评估，输出 MAE/RMSE/高眩光区误差 | 指标表和对比图 |
| 4.3-5.0 h | 写研究报告和答辩口径 | 可展示材料 |

如果必须使用 BlenderProc/Mitsuba 光追，5 小时内的风险会明显增大。只有在环境已安装、脚本模板已有、资产和材质预设已经准备好的情况下，才建议把光追纳入 5 小时闭环。

## 10. 5 小时内的优化策略

推荐优化：

- 图像分辨率先用 `64×64` 或 `128×128`。
- 焦距层数先用 `7-11` 层。
- 先训练 Tiny U-Net，不训练大模型。
- 合成图像和焦点图缓存到磁盘，避免重复生成。
- 先用近似物理模型，后续再替换为光追渲染。
- 使用混合精度或 CUDA，但保留 CPU 兜底路径。
- 指标只做 MAE、RMSE、P90、高眩光区 MAE、边缘误差，不做过复杂统计。
- 真实数据只做分布对齐和无真值验证，不在 5 小时内强行做真实监督训练。

## 11. 并行推荐方向

### 方向 A：无深度学习的鲁棒 DFF

继续发展 GA-CG-DFF：

```text
眩光风险图 -> 加权焦点评价 -> 峰值置信度 -> 鲁棒峰拟合 -> 保边补全
```

优点是解释性强，适合结题和论文方法章节。

### 方向 B：偏振/HDR 采集

如果后续可补实验，交叉偏振和多曝光 HDR 的收益可能大于继续换滤波器：

- 交叉偏振压制镜面反射。
- 多曝光避免高光区域饱和。
- 锁曝光/锁增益减少跨层亮度漂移。

### 方向 C：合成到真实的域适配

用真实焦距堆栈统计亮度、饱和比例、噪声和纹理频谱，再随机化合成数据：

```text
synthetic clean -> camera/glare/noise randomization -> real-like synthetic
```

这比单纯“多生成数据”更重要。

### 方向 D：样品特异算法

不同样品可用不同先验：

- 金属孔洞：眩光 mask + 凹坑拓扑约束。
- 钥匙纹路：线结构检测 + 沟槽方向约束。
- 3D 打印层纹：周期纹理方向 + 层高连续性约束。

这与用户当前判断一致：更好的识别结果需要结合样品特征或工业相机成像噪声/像差机理。

### 方向 E：标准样块验证

如果后续要把研究从“可行性”推进到“可信精度”，最该补的是标准真值，而不是更复杂网络：

- 标准台阶高度样块。
- 标准粗糙度样块。
- 激光共焦/白光干涉对比。
- 微米标尺或已知刻线样品。

## 12. 可写进结题或后续展望的表述

后续研究可引入仿真数据驱动的抗眩光 DFF 方法：首先生成具有已知深度真值的金属表面模型，在几何上模拟加工刀纹、划痕、凹坑和随机粗糙度，在成像上模拟金属镜面反射、局部眩光、传感器饱和、Poisson-Gaussian 噪声和跨焦距层亮度漂移；随后利用模拟焦距堆栈训练轻量深度恢复网络，使模型学习在高亮和低置信区域中修正传统聚焦评价的误差。初步轻量原型表明，该路线可以在合成数据上完成从真值生成、眩光成像、DFF 基线、网络训练到误差评估的闭环，但真实工业泛化仍需引入物理光追、真实相机标定、域适配和标准样块验证。

进一步的高分辨率仿真样本表明，在倾斜平面、较大深度范围、同轴光照和杂散光条件下，传统 DFF 的误差会受到焦距采样间隔、高光伪纹理和低频杂散光共同影响。低分辨率 CNN 不能直接迁移到 360p/540p 场景；经过高分辨率 patch 微调后，大深度凹坑和复合缺陷的恢复效果明显改善，但细微刀纹和窄槽结构仍有被平滑的风险。因此后续网络应采用多尺度 patch 训练、边缘保持损失和真实样品域适配，而不是只追求合成数据上的平均误差降低。
