# 焦距堆栈高度方向约定

本项目统一采用以下约定：

```text
焦距堆栈第 1 张图像 = 较高焦平面
后续图像 = 向较低焦平面扫描
```

因此，最佳聚焦层索引 `idx` 到相对高度的转换不是 `idx / (N - 1)`，而是：

```text
height_norm = 1 - idx / (N - 1)
```

所有新代码应优先调用：

```python
from dff_depth_direction import focus_index_to_relative_height, focus_index_to_height_um
```

不要在新脚本中手写 `idx / (N - 1)` 或 `np.linspace(0, height_range, N)` 作为 DFF 高度映射，除非明确处理的是低到高采集序列。
