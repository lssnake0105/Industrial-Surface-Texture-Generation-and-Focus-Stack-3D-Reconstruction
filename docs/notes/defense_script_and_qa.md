# 结题答辩讲稿与 Q&A（最终版）

## 5 分钟讲稿

1. 开场：本项目围绕多材料表面缺陷检测，使用变焦显微焦距堆栈和 DFF 方法恢复相对三维形貌；结题阶段进一步围绕眩光问题做了仿真域深度模型验证。
2. 中期路线衔接：中期提出的路线是采集原型、DFF 三维重建和深度学习接口。后续发现 SG 空间滤波改善有限，主要瓶颈转为同轴光照下的眩光和杂散光。
3. 真实样品成果：展示 3D 层纹、3D 表面、磕碰孔和钥匙纹路四组真实焦距堆栈结果，说明系统可以输出代表帧、相对高度图、伪彩色图和三维表面。
4. 仿真与模型：介绍三维样品生成器，补充山峰、山脊、阶跃、周期、V 谷、A 型刃脊和凹坑等样品，所有最终样品采用 17 层焦栈。
5. P10 结果：P10 是最终选定的宽谷粗糙平底样品，传统 DFF MAE 为 199.01 um，模型 MAE 为 92.46 um，相对改善 53.54%。
6. 总结：测试集平均 MAE 从 104.09 um 降至 57.31 um。项目完成了真实 DFF 重建和后续深度学习路线验证，但真实绝对精度和真实工业训练仍是后续工作。

## 高频 Q&A

Q1：为什么不直接说已经完成深度学习缺陷检测？
A1：因为真实样品没有足够标注和可靠高度真值，直接声称真实训练不严谨。本项目把深度学习放在仿真域验证，证明路线可行，并保留真实数据迁移接口。

Q2：高度结果是否是绝对测量？
A2：真实样品部分按相对高度解释，主要用于缺陷定位和三维可视化；仿真样品有真值，因此能计算 MAE。后续需要轮廓仪或标准台阶块才能给出真实绝对精度。

Q3：眩光降权 DFF 为什么有时不如传统 DFF？
A3：降权规则是启发式方法，能抑制部分眩光误判，但也可能削弱真实边缘信息。因此最终更可靠的方向是把眩光风险、DFF 先验和焦栈信息交给模型共同判断。

Q4：创新点是什么？
A4：一是完成低成本焦距堆栈 DFF 三维重建流程；二是把眩光/杂散光作为主要光学噪声机理进行分析；三是开发三维样品生成器并形成多类型仿真训练验证闭环。

Q5：如果继续做，最优先补什么？
A5：优先补真实高度真值，例如标准台阶块、轮廓仪对照或共聚焦测量；其次补光照控制，包括偏振片、漫射光、环形光和曝光 bracketing；最后做仿真到真实的迁移训练。
