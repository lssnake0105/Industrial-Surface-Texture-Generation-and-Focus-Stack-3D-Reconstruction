# 眩光感知 DFF 后续路线：把强反射作为主要光学噪声/像差方向

## 1. 核心判断

在当前多材料样品中，眩光/强反射应当作为后续算法探索的主线之一，但表述要精确：问题不只是“大面积 255 饱和”，而是**金属、镀层、光滑塑料等表面在局部形成高亮、反射梯度和跨层亮度不稳定，使 Laplacian/LoG 聚焦评价产生伪峰或低置信峰**。

也就是说，眩光对 DFF 的伤害主要有三类：

1. **硬饱和**：像素接近 255，纹理信息被截断，Laplacian 响应不再代表真实清晰度。
2. **软眩光/高亮斑**：未达到饱和，但局部亮度过高、梯度过强，会被焦点评价函数误认为“清晰边缘”。
3. **跨层亮度漂移**：样品随 Z 向扫描轻微离焦时，高光位置和强度变化，导致焦点曲线出现多峰或伪峰。

因此后续主线建议命名为：

**GA-CG-DFF：Glare-Aware Confidence-Guided Depth from Focus**  
中文：**眩光感知与置信度引导的变焦显微三维重建算法**。

这个名字比单纯“滤波优化”更像一个可以继续做下去的科研方向。

关键结果：

| 样品 | 现象 | 结论 |
|---|---|---|
| 钥匙纹路 | 近饱和和高亮候选比例最高 | 可作为眩光主线的主要展示样品 |
| 金属表面磕碰孔 | 硬饱和比例低，但局部高亮和低置信区域明显 | 适合说明强反射不一定表现为大面积 255 饱和 |
| 3D 打印层纹 | 饱和不明显，但平均焦点置信度低 | 问题更偏低纹理/散射纹理和焦点曲线不稳定 |
| 3D 打印表面 | 饱和不明显，置信度偏低 | 可作为非金属对照样品 |

原型验证中，低置信补全掩膜面积约为 5.7%-7.9%，说明补全操作集中在少量风险区域；边缘保留比约为 0.82-0.89，说明补全后没有把结果过度抹平。由于没有标准样块真值，这些指标只能证明输出完整和修改受控，不能证明绝对测量精度提升。

因此，不建议在报告中写成“所有样品都存在严重饱和眩光”。更稳妥的写法是：

> 在金属和镀层样品中，高亮反射对聚焦评价函数影响明显；在非金属样品中，虽然硬饱和不突出，但低纹理、散射纹理和亮度非均匀同样会降低焦点置信度。因此后续算法应统一处理“强反射/亮度非均匀/低置信聚焦响应”，而不只是做最终高度图滤波。

## 3. 优先度执行方案

### 优先级 A：眩光/高亮掩膜 + 聚焦评价降权

这是最值得优先做的方向，因为它直接针对当前 DFF 的错误来源。

#### 3.1 输入端诊断

对每一层图像 `I_k(x,y)` 计算：

```text
S_k(x,y) = 1, if I_k(x,y) > T_sat
H_k(x,y) = 1, if I_k(x,y) > T_high 或 局部亮度显著高于邻域背景
G_k(x,y) = |∇I_k(x,y)|
```

其中：

- `S_k`：硬饱和掩膜。
- `H_k`：软眩光/高亮候选掩膜。
- `G_k`：亮度梯度，辅助识别高光边缘。

阈值不要只用固定 250。建议结合：

- 固定饱和阈值：`I > 245` 或 `I > 250`。
- 分位数阈值：当前堆栈的 `P99.5`。
- 局部对比阈值：`I - local_median(I) > τ`。

这样能同时覆盖硬饱和和没有达到 255 的软眩光。

#### 3.2 眩光风险图

把每层高亮掩膜沿 Z 轴聚合：

```text
R_glare(x,y) = mean_k H_k(x,y)
```

再做轻度膨胀/高斯扩散，因为高光边缘附近也会污染 Laplacian 响应：

```text
R_glare = blur(dilate(R_glare))
```

`R_glare` 不是二值标签，而是一个 0-1 风险权重。

#### 3.3 聚焦评价降权

原始 DFF 是：

```text
z0(x,y) = argmax_k F_k(x,y)
```

眩光感知版本改为：

```text
F'_k(x,y) = F_k(x,y) * W_k(x,y)
W_k(x,y) = (1 - α S_k) * (1 - β H_k) * texture_score(x,y)
z0(x,y) = argmax_k F'_k(x,y)
```

解释：

- 饱和区域不完全删除，而是强降权。
- 高亮候选区域中等降权。
- 低纹理区域也降低权重，避免噪声主导深度估计。

这一步比“后处理滤波”更关键，因为它在焦点层选择之前就减少伪峰影响。

### 优先级 B：眩光区域置信度图 + 保边补全

聚焦层选完后，不要直接相信所有高度点，而是输出深度和置信度。

建议置信度：

```text
C(x,y) = peak_confidence * texture_confidence * (1 - R_glare)
```

其中：

- `peak_confidence`：主峰/次峰比、峰宽、峰曲率。
- `texture_confidence`：局部方差或 Tenengrad 能量。
- `1 - R_glare`：眩光风险惩罚。

对低置信度区域，用周围高置信度点和图像边缘进行补全：

```text
min_z Σ_i C_i(z_i - z_i0)^2 + λΣ_ij w_ij(z_i - z_j)^2
```

其中 `w_ij` 在真实缺陷边界处变小，避免把孔洞和沟槽抹平。

### 优先级 C：面向眩光的采集改进

如果后续还有机会做实验，硬件/采集端的收益会比继续换滤波器更高。

推荐顺序：

1. **交叉偏振**：光源加起偏片，相机前加检偏片，压制镜面反射。
2. **多曝光 HDR 焦距堆栈**：每个 Z 层拍短曝光和正常曝光，融合避免饱和。
3. **环形光/漫射光照明**：减弱单方向强反射。
4. **曝光锁定与增益锁定**：避免自动曝光导致跨层亮度漂移。
5. **暗场/平场校正**：分离相机偏置、像素响应不均和照明不均。

在结题答辩中，可以把这些作为“后续系统改进”而不是当前成果。

## 4. 可执行算法流程

```text
输入：焦距堆栈 I_k(x,y)

1. 成像预校正
   - 灰度归一化
   - 可选暗场/平场校正
   - 自动曝光漂移校正

2. 眩光风险检测
   - 固定阈值检测硬饱和
   - 分位数阈值检测软高亮
   - 局部中值差分检测局部强反射
   - 沿 Z 轴聚合为 R_glare(x,y)

3. 聚焦评价
   - Laplacian / Tenengrad / SML 计算 F_k(x,y)
   - 用 W_k(x,y) 对眩光和低纹理区域降权

4. 深度估计
   - 对 F'_k(x,y) 做峰值搜索
   - 对高置信像素做二次/Gaussian 峰值拟合
   - 输出 z0(x,y) 和 C(x,y)

5. 置信度引导补全
   - 高置信区保留
   - 低置信区使用边缘引导插值/优化
   - 缺陷边界处降低平滑，保留沟槽和孔洞

6. 样品特异分析
   - 3D 打印：层纹方向与周期
   - 金属凹坑：反光掩膜 + 凹坑拓扑
   - 钥匙沟槽：线结构检测 + 横截面轮廓
```

## 5. 与 SG 空间滤波的关系

你已经做的 SG 空间滤波应该放在流程后段：

```text
原始 DFF 高度图 -> SG 空间滤波 -> 改善表面连续性
```

但后续主线应该升级为：

```text
焦距堆栈 -> 眩光风险图 -> 加权聚焦评价 -> 置信度深度图 -> 保边补全 -> 可选 SG 空间保形平滑
```

也就是说，SG 空间滤波仍然有价值，但它应作为最后的轻量保形处理，而不是主算法。

## 6. 仿真数据驱动的抗眩光扩展

在 GA-CG-DFF 启发式路线之外，还可以并行推进“仿真真值 + 抗眩光深度学习”的研究方向。这个方向的核心价值是补足当前真实样品缺少标准高度真值的问题：

```text
可控三维深度真值 -> 金属加工纹理/凹坑/划痕 -> 金属反射与眩光成像 -> 模拟焦距堆栈 -> DFF基线误差 -> 抗眩光网络训练
```

我已完成一个轻量 Python 原型 `simulate_antiglare_prototype.py`，输出位置：

`结题交付包/05_图表与结果/仿真抗眩光原型/`

该原型生成单一金属表面深度真值，引入加工纹理、凹坑、划痕、粗糙度扰动、镜面高光、bloom、Poisson-Gaussian 噪声、PRNU/DSNU 和 8-bit 量化，并训练一个 Tiny U-Net 风格 CNN 从模拟焦距堆栈中恢复相对深度。合成验证集中，DFF 基线归一化 MAE 为 `0.1093`，TinyCNN 为 `0.0666`，说明 5 小时内可以完成“真值生成-成像仿真-DFF 基线-网络训练-误差评估”的概念闭环。

需要严格说明：该结果只证明合成域闭环可行，不证明真实工业样品泛化已经完成。若要发展为更严谨研究，应将当前近似成像模块替换为 BlenderProc/Blender-Cycles 或 Mitsuba 3 光追，并引入真实焦距堆栈的域适配和标准样块验证。

详细方案见：

`仿真抗眩光研究方案.md`

进一步扩展中，已生成 360p/540p 高分辨率样本，加入倾斜平面、细微刀纹、多尺度凹坑、深凹坑抬边、同轴光照和杂散光。结果显示，64×64 合成闭环得到的小模型不能直接稳定迁移到高分辨率场景；经过 128×128 高分辨率 patch 微调后，六组样本平均 MAE 从 DFF 的约 `80.60 um` 降到 `54.58 um`，但细微刀纹和窄槽仍存在被平滑风险。因此该方向后续应优先发展多尺度 patch 训练、边缘保持损失和真实域适配。

同时，传统 DFF 基线的 Z 向步长确实需要调整。以 540p 大深度复合凹坑为例，9 层焦距堆栈约为 `181.25 um/层`，DFF MAE 为 `149.42 um`；17 层约为 `90.62 um/层`，MAE 降至 `96.63 um`；25 层约为 `60.42 um/层`，MAE 降至 `74.86 um`。但 360p 深凹坑中 25 层反而较 17 层变差，说明更密采样需要配合主次峰置信度、亚层峰值拟合和眩光伪峰抑制，不能只增加层数。

最新主流程已统一采用 17 层焦距堆栈，并新增 `A 型突起刃脊 + 柏林噪声` 样品。该样品由 `surface_sample_generator.py` 生成，属于尖锐突起脊线结构，能更好测试模型对刃口/峰线和粗糙噪声的保持能力。17 层 patch 模型重新训练后，七组高分辨率样本平均 MAE 从 DFF 的约 `69.69 um` 降至 `30.51 um`；A 型刃脊样品从 `124.58 um` 降至 `48.01 um`。但细微刀纹和细槽仍可能被平滑，因此后续仍需多尺度输入和边缘保持损失。

## 7. 可直接写进结题报告的表述

中期之后，项目尝试将 Savitzky-Golay 局部多项式拟合思想引入二维空间滤波，对重建高度图进行保形平滑。该方法相较普通高斯平滑能更好保留局部曲面趋势，最终效果略有改善，但提升有限。进一步分析发现，当前 DFF 重建误差的主要来源并不只是高度图上的随机噪声，而是金属、镀层和光滑表面产生的强反射/眩光会在焦距堆栈中引入局部高亮、饱和截断和跨层亮度漂移，导致 Laplacian/LoG 聚焦评价出现伪峰或低置信峰。后处理滤波无法纠正已经选错的焦点层。

因此后续将以眩光影响作为光学噪声/像差机理的主要研究方向，构建眩光感知与置信度引导的 DFF 算法。该算法将在输入端检测硬饱和与软高亮区域，生成眩光风险图；在聚焦评价阶段对高亮和低纹理区域降权；在深度估计后输出置信度图，并对低置信区域进行边缘引导补全。这样可以把算法改进从“结果图平滑”前移到“焦点层判定”，更符合工业相机成像噪声和多材料反射差异的实际机理。
