# External SOTA Main-Table Eligibility Audit

Updated: 2026-06-18

Purpose: define a reproducible audit gate for deciding whether DFV, DDFFNet, or any future external method can enter the manuscript's main synthetic comparison table.

## 1. Audit Principle

An external baseline should enter the main table only when the evidence proves three things:

1. the method was evaluated on the intended synthetic split;
2. the prediction files, scale alignment, and training setting are documented;
3. the reported numbers are generated by the same metric pipeline used for project-aligned evaluation.

This audit is a manuscript-safety gate. Passing the audit does not automatically prove that the method is state of the art; it only proves that the result is eligible to be considered for the main comparison table.

## 2. Required Inputs

| Input | Default path | Role |
|---|---|---|
| export manifest | `tmp/external_baseline_data/manifest.csv` | defines exported samples and expected split coverage |
| prediction manifest | method-specific path under `tmp/external_baseline_results/` | lists method, training setting, sample id, prediction path, scale mode, and clip flag |
| batch result directory | method-specific path under `tmp/external_baseline_results/` | contains `per_sample_metrics.csv` and `method_summary_metrics.csv` |
| run log | `tmp/external_baseline_results/<method>/logs/` | records code source, environment, command, failures, and scale decisions |

## 3. Eligibility Levels

| Level | Meaning | Manuscript handling |
|---|---|---|
| Eligible-main-table | all required gates pass | can be reported in the main synthetic quantitative table |
| Eligible-auxiliary | predictions exist but coverage, scale, or training evidence is incomplete | use in auxiliary table or qualitative discussion |
| Not eligible | missing predictions, missing metrics, or unverifiable settings | keep in Related Work or future work |

## 4. Hard Gates

| Gate | Pass condition |
|---|---|
| prediction coverage | prediction manifest contains every required sample or explicitly documents skipped samples |
| prediction files | every listed `.npy` file exists |
| result files | `per_sample_metrics.csv` and `method_summary_metrics.csv` exist |
| metric consistency | per-sample rows match prediction manifest rows by method and sample id |
| training setting | no row has an empty or unknown training setting |
| scale mode | every row states one of `raw_norm`, `minmax`, `affine`, or `scale_to_um` |
| minimum sample count | more than a single smoke-test sample is required; script default is at least 2 samples for main-table eligibility |
| no accidental single-sample claim | one-sample P10 smoke results cannot be labeled as full main-table results |
| run log | at least one log file is available for the method under `tmp/external_baseline_results/<method>/logs/` |

## 5. Scale-Mode Interpretation

| Scale mode | Main-table risk | Recommended handling |
|---|---|---|
| `scale_to_um` | low if mapping is physical and documented | main table allowed |
| `raw_norm` | medium, depends on output convention | main table allowed only if output scale is documented |
| `minmax` | medium/high | report as scale-aligned result |
| `affine` | high if fitted per sample using GT | auxiliary or clearly labeled scale-aligned table |

## 6. Tool

Use:

```powershell
python -X utf8 submission_planning/tools/audit_external_sota_eligibility.py `
  --prediction-manifest tmp/external_baseline_results/DFV/prediction_manifest.csv `
  --batch-result-dir tmp/external_baseline_results/DFV/batch_evaluation `
  --method DFV `
  --min-samples-for-main-table 2
```

The script writes a JSON report and a Markdown report to the selected output directory. It only reads manifests and result tables; it does not run external models or modify project source data.

## 7. Current Status

As of 2026-06-18, no DFV/DDFFNet prediction manifest exists. Therefore no external deep DFF method is eligible for the main synthetic table yet. Current P10 DFF/GADFF prior smoke results are useful for validating the metric pipeline only.
